# AuraPaper 光影壁纸

基于 **C++20 + Qt Quick 6.8 + Windows 原生 COM / WinRT API** 开发的现代桌面与锁屏壁纸自动更换软件。

## 核心功能
- **桌面壁纸与锁屏壁纸完全独立引擎**：两个通道拥有独立的文件夹路径、更换间隔、排序方式、图片适应模式与启停控制，互不干扰。
- **更换顺序**：支持文件名升序（自然数字排序）、文件名降序、智能防重复洗牌随机轮换、按最新修改时间排序。
- **图片适应模式**：
  - 桌面壁纸：填充 / 适应 / 拉伸 / 平铺 / 居中 / 跨区（通过 Windows `IDesktopWallpaper` COM 接口实时生效）。
  - 锁屏壁纸：填充 / 适应 / 拉伸 / 平铺 / 居中（通过 WinRT `LockScreen::SetImageFileAsync` 设置，非填充模式及 WebP 格式自动按主屏物理分辨率高质量渲染适配）。
- **黑白主题无缝切换**：深邃暗黑主题与纯净浅白主题一键切换，全界面平滑颜色过渡并同步 Windows 11 DWM 窗口外观。
- **开机自启动与系统托盘**：
  - 支持写入当前用户启动项注册表（`HKCU\...\Run`），可选自启动时静默最小化到托盘（`--minimized`）。
  - 托盘菜单支持快速切换桌面/锁屏壁纸、独立启停自动更换与一键恢复主界面。
- **拓展功能**：
  - 总览双引擎实时预览面板与环形倒计时。
  - 虚拟化壁纸图库浏览、实时文件名搜索过滤、点击即换、支持文件夹拖拽导入与目录变动自动监控。
  - 全屏游戏 / 影音播放时自动暂停切换（`SHQueryUserNotificationState`）。
  - 单实例防重复启动与配置自动持久化。

## 低内存与资源优化
- 异步按需缩略图解码（`QQuickAsyncImageProvider` + `QImageReader::setScaledSize`），避免将 4K/8K 原图常驻内存。
- 虚拟化图库网格与按需懒加载页面，避免多余 GPU FBO 纹理常驻。
- 最小化至系统托盘后自动停止 UI 轮询定时器、回收场景纹理与工作集内存（后台托盘驻留内存可低至约 **1 MB**），且界面隐藏时所有装饰动画自动暂停（0% 后台渲染开销）。

## 构建与运行
已预编译完成，可直接运行：
```text
build\AuraPaper.exe
```

如需重新编译并部署 Qt 运行库，直接运行根目录脚本：
```bat
build.bat
```
